Reglas de Aplicación para el Sitio Web

1. Jerarquía Clara No uses más de un botón con fondo #183B2D por área visual visible. Combínalo con variantes outline o enlaces editoriales de texto.
2. Terracota como Acento Cultural El color barro (#C35D38) se reserva para talleres de cerámica, historia y elementos conmemorativos del patrimonio de Camagüey.
3. WhatsApp como Conversión Rápida El verde esmeralda brillante (#10B981 / #22C55E) está reservado exclusivamente para la comunicación y reservas directas por chat.
